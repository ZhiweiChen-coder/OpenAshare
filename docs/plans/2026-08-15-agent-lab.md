# Agent Lab Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在现有 `/work` 三栏工作台内增加 `?mode=lab` 实验模式，让用户直接运行 Agent query 并观察工具调用、回答摘要、引用和 payload 结构。

**Architecture:** Lab 模式复用现有 `AgentChat` 和真实 SSE，不复制 Agent 请求逻辑。`AgentChat` 通过可选的实验事件回调向 Workspace shell 报告 trace；Workspace shell 只在 URL 打开 lab 模式时渲染顶部实验控制条，普通 `/work` 保持原样。

**Tech Stack:** Next.js App Router、React、TypeScript、现有 `streamAgent` SSE client、CSS。

---

### Task 1: 扩展实验事件类型和 AgentChat 触发接口

**Files:**
- Modify: `lib/workspace.ts`
- Modify: `components/agent-chat.tsx`

1. 增加 `AgentLabTrace` 类型，包含阶段、工具、消息、进度、时间和最终 response 摘要信息。
2. 为 `AgentChat` 增加可选 `onLabTrace` prop。
3. 在 workspace 模式监听 `ashare:run-prompt` 自定义事件，调用现有 `ask()`。
4. 将已有 SSE `onEvent` 转换为 lab trace；不记录完整 payload，只保留工具名、阶段和安全摘要。

### Task 2: 增加 `/work?mode=lab` 实验控制条

**Files:**
- Create: `components/agent-lab-bar.tsx`
- Modify: `app/work/page.tsx`
- Modify: `components/workspace-shell.tsx`

1. `app/work/page.tsx` 读取 `mode`，只把 `mode=lab` 传给 shell。
2. Lab bar 提供自由输入、预设 query、运行按钮和清空 trace 按钮。
3. 预设覆盖股票分析、股票新闻、泛热点、联网搜索、模糊问题和多轮追问。
4. 显示最近一次 run 的状态、工具调用序列、引用数量、payload key 和回答长度。
5. 通过 DOM 自定义事件触发中央 AgentChat，保证实验请求与真实产品请求完全相同。

### Task 3: 完成视觉和交互细节

**Files:**
- Modify: `app/globals.css`

1. 使用现有暖白研究舱视觉，增加低干扰的 lab toolbar、trace chips 和状态色。
2. 保证 1440px、1024px 和窄屏下实验条不会遮挡输入框；小屏允许横向滚动预设。
3. 不在默认 `/work` 渲染任何 lab 控件。
